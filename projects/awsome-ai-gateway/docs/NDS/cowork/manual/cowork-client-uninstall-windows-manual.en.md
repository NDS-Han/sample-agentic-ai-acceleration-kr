# Remove a manual Windows Cowork setup

[한국어](cowork-client-uninstall-windows-manual.md) · **English** · [Cowork guides](../README.en.md)

Confirm whether the device uses the manual setup or the [packaged installer](../installer/cowork-installer-uninstall-windows.en.md). Identify which clients share each helper, package and credential store before making changes.

1. Quit Claude Desktop and back up the managed settings you are authorized to change.
2. Remove the Cowork policy and helper only within the intended scope. Confirm separately whether to uninstall the application.
3. Clear the intended user's gateway session if required. Verify Claude Code and Codex if they share the gateway CLI or a helper path.
4. Restart the app or deploy the replacement configuration and verify its startup behavior.

Use the [original uninstall commands and verification table](cowork-client-uninstall-windows-manual.md) for the applicable registry and profile paths.
