## 캡처 범위

- 목록, 상세 화면, 하위 탭, 필터, 등록·편집 양식과 확인 창을 열었습니다. 반복되는 목록과 양식은 대표 항목으로 보여 줍니다.
- Cognito 동기화, 정책·예산 저장, 모델 상태 변경, 팀 재인증, 키 발급·폐기, 로그 수집 변경, 로그아웃은 실행하지 않았습니다.
- 캡처 당시 활성 API 키가 0개여서 폐기 확인 창에 진입할 수 없었습니다. 본문 로그는 **Sessions**와 **By request**의 메타데이터만 캡처했습니다.
- 분석 내보내기는 메뉴까지만 열었습니다. BI Insight는 초기 화면, Integration과 CLI는 연결 및 설치 안내 화면을 담았습니다.
- Dashboard의 기간 선택과 Monitoring의 유형 선택은 브라우저가 별도로 그리는 옵션 레이어를 사용합니다. 해당 PNG에는 선택 컨트롤이 표시됩니다.
