# R7 외부 비용 대조 설계

**한국어** · [English](cost-reconciliation-r7.md) · [NDS 문서](README.md)

설계 단계입니다. 운영 중인 R1–R6 작업은 게이트웨이 내부 원장과 집계를 대조합니다. R7은 AWS 호출 기록과 청구 데이터를 가져와 게이트웨이 기록과 비교하는 별도 작업의 설계입니다.

| 범위 | 비교 |
|---|---|
| 일별 요청 단위 | Bedrock 호출 로그 요청 ID와 게이트웨이 기록. 토큰 일치, 추정값, 양쪽의 미기록을 구분합니다. |
| 일별 시간 집계 | CloudWatch의 모델별 토큰과 게이트웨이 시간별 집계. 게이트웨이를 거치지 않은 호출도 차이로 드러날 수 있습니다. |
| 월별 금액 | CUR과 게이트웨이의 모델·토큰 유형 및 AgentCore 검색 비용. 가격 시점, 계약 단가, 무료 구간, 추정 비용이 차이에 영향을 줍니다. |

요청 ID가 없는 Mantle 호출과 단일 행에 여러 요청을 합친 웹 검색은 유형별로 집계합니다. AWS 비교를 활성화하려면 대상 계정, 로그 접근, Athena 및 CUR 위치와 결과 저장 방식을 결정해야 합니다. [상세 설계와 미결 항목](cost-reconciliation-r7.md)
