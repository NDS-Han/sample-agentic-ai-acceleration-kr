### 읽는 법

- **차이의 대부분은 첫 질문에서 난다**(① 이 −51%) — 첫 요청에서 앱의 시스템 프롬프트와 도구 정의가 캐시에 기록되는데, Cowork 탭이 그 앞부분이 훨씬 크다(① 의 캐시 기록 69,231 대 35,782). 뒤 질문들은 그 앞부분을 **캐시 읽기**로 다시 읽으므로 읽기 토큰도 같은 비율로 벌어진다.
- **두 데모 모두 캐시 기록이 비용의 절반 이상**(55% · 51%)이고, 입력 토큰은 1.5% 뿐이다 — 데모 비용을 줄이려면 검색 횟수보다 "앞부분이 작은 탭" 과 "짧은 대화" 가 더 효과가 크다.
- **출력은 A 가 18% 더 많다** — 같은 내용이면 한국어가 영어보다 토큰을 더 쓰는 경향이 있지만, 두 데모는 **탭과 언어가 함께 다르다**. 어느 쪽이 얼마를 설명하는지는 이 두 번의 실행으로 가를 수 없다.
- **④ 는 거의 같다**(−6%) — 파일 내용을 쓰는 출력 토큰이 비용을 좌우하고, B 는 요청이 1건 더 있었다(파일 공유 단계).
- 여기 비용은 **모델 토큰 비용만**이다. 검색 커넥터(AgentCore) 호출 요금은 AWS 에서 따로 청구되고 `usage_logs` 에 없다(검색 A 6회 · B 5회).
- 각 1회 실행이다 — 같은 질문도 돌릴 때마다 검색 횟수와 답 길이가 달라진다. 어림으로는 **데모 1회 = Cowork 탭 약 $0.6 · Chat 탭 약 $0.4**(Sonnet 5 · effort `xhigh`).
